# 新卡资料基本索引

预读日期：2026-10-26。目标：将新卡用于用户之前那台四轴机械臂，先交付Windows离线演示和明确触发的通信回显诊断。

这次预读覆盖教程目录与关键章节、接线示意图、三份原理图的器件/接口检索，以及三轴、四轴、SCARA、汇川、Boot源码中的网络、回显、常规状态和初始化路径。没有通读每个底层库、视觉模块或所有教学章节，也没有编译或刷写原厂固件。

## 从哪里读起

| 要解决的问题 | 入口 | 目前结论 |
| --- | --- | --- |
| 了解接口和接线 | 教程第13–15页，硬件原理图002三份 | 24V供电；电脑网口与EtherCAT网口分开；16路低有效输入、14路NPN开漏输出为教程描述，实物版本和负载额定值仍需核对 |
| 先让电脑与卡说上话 | 教程第35–41页；三轴包 `4.1.1` demo；[协议核对](PROTOCOL.md) | UDP，不是旧博派GA SDK；资料默认PC .12:6000、卡 .20:5000；卡固定目标回包 |
| 理解回零和单轴运动 | 教程第42–66页；`Eth_Task.c`的0x68、`ECAT_AxisControl.c` | 协议ACK只代表请求接收，不能代表回零/运动完成；本次没有实现真实运动发送 |
| 查I/O | 教程第85–100页及原理图第2份 | 不可把任意输出当成磁吸口；接口、驱动电流、续流和反馈需实物确认 |
| 查插补和拱门 | 第67–84、101–166页 | 三轴/四轴/SCARA实现各有差异，不能因机械臂有四轴就直接刷四轴龙门程序 |
| 识别Boot和升级边界 | 第167–181页；Boot017 `Eth_Task.c` | Boot不回显72字节挑战，本demo拒绝将其认作App通信通过；不提供升级操作 |
| 查完整产品上位机 | 第182页以后；各结构的C#产品源码 | 可用于后续功能参考，含配置/工艺/视觉等大量超出首版范围的逻辑 |
| 回看旧卡经验 | 旧仓库 `thinkbook-deploy/payload/source/EtherCATDemo` | 参考四轴布局、反馈有效性与适配器分层；不沿用GA接口、状态掩码或电机圈数比例 |

教程的PDF实际页序与印刷页码一致，共377页。两份教程逐字节相同，读其中一份即可。

## 硬件资料导航

- 原理图第1份：主控、存储、串口、网络等，文本可检索 `HC32`、`W5500`、`SP3232EEN`、`MB85RS128BPNF`。信号名仍含STM32字样，不能单靠网名认定主控型号。
- 原理图第2份：输入/输出、隔离与RS485，可检索 `LTV217A`、`SP3485EEN`、`ExternOutput`。
- 原理图第3份：EtherCAT主站模块与PHY，可检索 `Ethercat_Master`、`SPI_Ether`、`IP101GRI`。
- 教程第14页的板卡布局适合辨认接口；它不能代替当前实物丝印、板卡版本与电气额定值核对。

## 固件选择与待确认表

| 项目 | 已知 | 下一步需要的事实 |
| --- | --- | --- |
| 机械目标 | 用户确认还是原来的四轴机械臂 | 新卡软件轴0..3与四个实体关节的对应 |
| 升降轴 | 旧项目轴2是丝杆升降 | 新卡编号、方向、丝杆导程、传动比和有效行程 |
| SCARA结构 | 新资料含SCARA源码，但示例用固定臂长/零角 | 实际机构模型、两臂长度、零角、升降及末端转动关系 |
| 卡内固件 | 无实机证据 | App名称、版本/源码对应、驱动型号及当前网络配置 |
| 位置单位 | 各固件槽位和单位有差异 | 脉冲当量、角度/直线换算、零位与行程；不能照搬旧262144计数/圈 |
| 磁吸 | 旧项目尚无已确认控制接口 | 具体类型、输出驱动能力、反馈与断电保持行为 |
| 真实运行 | 本次只有源码核对、离线与回环验证 | 独立的实机通信、低速单轴验证和现场人工验收 |

## 来源与复查

所有原厂文件留在原资料目录，没有上传GitHub，也没有在同步目录放入开发环境或Agent配置。新增代码独立实现；索引中的“开源”来自原文件命名，不代表已审定原厂许可证。

本机可用标准Python重新计算清单（只读原件）：

```powershell
python scripts/index_materials.py "D:\你的新卡资料目录" --output docs/materials/manifest.json
```

脚本索引所指定目录的PDF/ZIP/RAR/7z；请传原件目录，不要把我们后来交付的zip混入原始指纹基线。详细源码链、函数和行号见 [PROTOCOL.md](PROTOCOL.md)。
